Data

A public credit-risk dataset of 32,581 loan applicants, cleaned to 32,409 and split once into training and test sets.

Source: Credit Risk Dataset by laotse, Kaggle (kaggle.com/datasets/laotse/credit-risk-dataset), downloaded with kagglehub in 01_clean_split.ipynb. Public data; no personal identifiers.

One row = one loan applicant and their loan. Size: 32,581 rows × 12 columns. Not documented: the country and the loan dates. The structure (grades A–G, MORTGAGE/RENT/OWN/OTHER, a $35,000 loan cap) matches US marketplace lending, so amounts are read as US dollars.

Also used: US prime lending rate and inflation from the World Bank Open Data API (12_macro_check.ipynb), to check whether the interest rates are realistic.

Missing values were not filled in here. Employment length (887) and interest rate (3,094) are filled with the median inside each cross-validation fold, learned from training rows only (see Method), so the test set never influences them. Rows without a rate cannot be used to train or test the rate models (nothing to learn from).

Class balance and the train/test split

Source: 01_clean_split.ipynb (split); folds: src/credit.py (make_cv)

21.9% of applicants defaulted (78.1% repaid). This is a moderate imbalance: a model that predicts "everyone repays" is 78% accurate but useless, which is why accuracy is not our main metric.

Stratified 80/20 split (random seed 42): 25,927 training and 6,482 test applicants, both 21.9% defaulters. The test set was saved once and not opened until the final evaluation.
